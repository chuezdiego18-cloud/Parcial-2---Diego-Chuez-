Inicio / UX vs. UI

Dos disciplinas, un mismo producto.

UX es cómo se siente usar algo. UI es cómo se ve y cómo se toca.

Cada una responde una pregunta distinta

UX Experiencia de usuario

Cómo se siente usar el producto de principio a fin.

  • ¿Se entiende a la primera?
  • ¿Es fácil llegar a lo que busco?
  • ¿Cuánto tiempo me toma?
  • ¿Resuelve de verdad mi problema?

UI Interfaz de usuario

Cómo se ve y cómo se toca lo que uso.

  • Colores y tipografías
  • Botones, menús e íconos
  • Espaciado y orden en pantalla
  • Coherencia visual entre páginas

Se necesitan las dos: una interfaz bonita pero confusa frustra, y una experiencia bien pensada con mala presentación no inspira confianza.
